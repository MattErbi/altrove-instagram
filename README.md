# altrove-instagram

File dei contenuti Instagram di Altrove (@aitrove.travel).
Ogni cartella `post/AAAA-MM-GG/` contiene le immagini o i video pubblicati quel giorno tramite Buffer.

La cartella `strumenti/reel-remotion/` contiene gli strumenti per i reel (Remotion + motore musicale animation-studio, MIT + suoni Kenney CC0 + font OFL): istruzioni nel suo README.
